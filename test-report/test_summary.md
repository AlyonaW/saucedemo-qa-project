# Project Overview
This project contains manual QA testing of the SauceDemo web application, focusing on the following modules:
- Login functionality
- Shopping Cart functionality

## Application Under Test:
https://www.saucedemo.com

## Testing Scope

- Functional testing
- UI/UX testing
- Negative testing
- Basic data integrity checks
