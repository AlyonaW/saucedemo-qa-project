# Login Page Checklist — SauceDemo
## Project: SauceDemo QA Testing
## Module: Login functionality
## URL: https://www.saucedemo.com

---

## Functional checks
- [ ] Login page loads successfully
- [ ] Username input field is visible
- [ ] Password input field is visible
- [ ] Login button is visible and clickable
- [ ] User can enter text into username field
- [ ] User can enter text into password field
- [ ] Password field masks input (shows dots/asterisks)
- [ ] Login works with valid credentials
- [ ] Error message appears with invalid credentials
- [ ] Error message appears when fields are empty

---

## UI/UX checks
- [ ] Login form is properly aligned
- [ ] No overlapping elements on the page
- [ ] Text is readable and not broken
- [ ] Button has proper hover/click state
- [ ] Error messages are clearly visible

---

## Negative testing
- [ ] Login with empty username
- [ ] Login with empty password
- [ ] Login with both fields empty
- [ ] Login with incorrect password
- [ ] Login with incorrect username

---

## Basic security checks
- [ ] Password is not visible in plain text
- [ ] User cannot login with random input
- [ ] Error messages do not reveal sensitive info
